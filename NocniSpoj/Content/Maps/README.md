# Mapy

V Unreal Editoru vytvoř:

1. `L_TrainPrototype` (Basic / Empty Open World → vyčisti, nech floor)
2. Umísti `TrainCarActor` (nebo BP child)
3. World Settings → GameMode Override = `NocniSpojGameMode`
4. Player Start na začátku vagónu
5. Přidej `TicketActor`, `LanternActor`, 1–2× `PassengerActor`
6. Project Settings → Maps & Modes → nastav tuto mapu jako Game Default / Editor Startup
